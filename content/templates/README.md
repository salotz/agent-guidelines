# Templates

This section provides explicit, concrete templates with complete choices of tools and standards for specific purposes.

Templates are provided as specifications and not an actual templating system like [copier](https://github.com/copier-org/copier) or [cookiecutter](https://github.com/cookiecutter/cookiecutter).
This is optimized more for understanding by humans and agents rather than providing a mechanism for automating project creation.

Templates can be applied at many different levels:

- host layouts
- projects
- project sub-sections

And so on.

The scope of each template is specified in the template itself.

## Available templates

- [Generic project template](./generic-project.md):
  opinionated defaults for starting a language-agnostic project (VCS, tooling, hooks, PRJX, agent layout, blobs).

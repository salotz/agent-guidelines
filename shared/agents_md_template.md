# Agent Guidelines

This project follows the guidelines at https://github.com/salotz/agent-guidelines, from which this section was directly copied.

- Read `shared/generic-agent-guidelines.md` (or equivalent) for agent-assisted work.
- Prefer task-specific tools over shell.
- Follow salotz RFC 22 (project layout), RFC 23/24 (host context).
- Cache remote resources locally when possible.
- Use compacted inlining for referenced standards.
- Check `shared/summaries/` before fetching full external standards.

See `shared/glossary.md` for term definitions.

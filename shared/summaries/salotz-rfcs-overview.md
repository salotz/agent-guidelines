# Summary: salotz RFCs

Source: https://github.com/salotz/rfcs

## Overview
Personal collection of RFCs (Requests for Comments) by salotz covering coding structure, agent context, naming, git practices, and related topics.

These RFCs are referenced throughout the agent-guidelines as the source of personal standards for:
- Project/AI coding structure (RFC 22)
- Local agent context (RFC 23)
- Extended XDG directories (RFC 24)
- And others (e.g. codetags, git commit messages, naming)

## Usage
When a specific `salotz.NNN_...` RFC is referenced, prefer the compacted summary for that RFC (see other files in this summaries/ directory).

The full collection is available at the link above for deeper reading when needed.

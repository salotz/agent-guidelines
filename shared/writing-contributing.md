# Writing contributors documentation

When writing documentation for contributors follow these guidelines.

## Don't recapitulate upstream documentation

When writing documentation don't overly describe what the upstream for documentation would tell a user.

Focus on the choices and design of the tool specific to the project.

If extra reminders or summaries are needed keep this in agent-specific context files.

Keep documents as terse and readable as possible. Humans are much slower at reading than agents so be careful to not give too much information (TMI).
